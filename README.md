# OG Time Tab

Extension Chrome de suivi du temps par onglet (temps ouvert + temps actif).

Voir **[agent.md](./agent.md)** pour l’architecture, les paramètres et les procédures de test.

## Installation rapide

1. `chrome://extensions` → Mode développeur
2. Charger le dossier `og-time-tab`
3. Popup → **Dashboard** / **Options**
